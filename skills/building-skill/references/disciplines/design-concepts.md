# Design Concepts: Creative AND Correct

Load this file when the task is "design me a house / tower / mosque / clinic / office", when a client asks for "a concept", or when a plan looks competent but lifeless. The aim is a building that is **inspired** (it has one clear idea) and **correct** (the climate, culture, program, and code all work). Creativity without correctness is a render; correctness without creativity is a box.

Everything numeric below is a **rule of thumb** for early-stage concept work. It is not a code or engineering value. Always verify against the local building code, a climate file (EPW), and a structural/MEP engineer before anything is built.

---

## 1. Concept generation method

### 1.1 The input sweep (do this before drawing anything)

Collect answers to these four lenses. If you do not know an answer, ask the client or state the assumption out loud.

| Lens | Questions that change the design |
|---|---|
| Site | Plot dimensions, orientation, slope, street side(s), neighbours' heights, trees, views worth keeping, views worth hiding, noise source, setbacks, easements |
| Climate | Climate zone, design temperature, humidity, prevailing wind, sun angle (summer and winter), rain, dust, flood risk |
| Program | Who lives/works here, how many, what rooms, what future growth, budget band, built-up area ratio allowed (FAR/coverage) |
| Culture | Family structure, privacy norms, hospitality customs (majlis, guest flow), religious needs (qibla, prayer room, ablution), local material pride, neighbourhood character |

Write one sentence per lens. The concept grows from the tension between those four sentences, not from a Pinterest image.

### 1.2 Three concept options, then pick one

Never present a single idea as if it were the only one. Generate three genuinely different organising ideas (a "parti" - the dominant organising idea, usually reducible to a basic diagram or one sentence; see the CUNY and SCI-Arc studio material in Sources).

Make them different along ONE axis so the client can compare:

| Option | Organising idea | Example (Gulf villa, 600 m2 plot) |
|---|---|---|
| A. Introverted | Rooms wrap a courtyard; blank street face | U-shaped plan around a shaded court, majlis at the front corner |
| B. Linear / bar | Long thin volume along the plot's long axis, one room deep | Cross-ventilated bar, north-south, garden on both sides |
| C. Stacked / compact | Small footprint, tall, maximum garden | Ground = reception + service, first = family, roof = terrace |

Scoring table (1-5 each, then pick the highest total and say why in two lines):

| Criterion | A | B | C |
|---|---|---|---|
| Fits site and setbacks | | | |
| Climate performance | | | |
| Privacy and cultural fit | | | |
| Program efficiency (circulation under ~15-20%) | | | |
| Buildable within budget | | | |
| Memorability / character | | | |

Keep the losing options in an appendix slide; clients like seeing what was considered.

### 1.3 Concept statement formula

A concept statement is one or two sentences a client can repeat at dinner. Formula:

> **[Building] is a [form/gesture] that [does what] in response to [site or climate fact], so that [people] experience [quality].**

Examples:
- "The villa is a shaded courtyard house that turns its back to the western sun and opens its family rooms to a north garden, so the household lives outdoors ten months a year."
- "The clinic is a single calm street under a timber ceiling that organises waiting, consulting, and treatment in a line, so a frightened patient always sees the exit and the daylight."
- "The mosque is a quiet cube lifted by a ring of light between wall and roof, so the prayer hall feels held rather than enclosed."

Test: if you could swap the nouns and still use the sentence for a different project, it is too generic. Rewrite with a real site/climate/culture fact.

### 1.4 Diagrams to produce (in this order)

Diagrams are thinking tools, not decoration. One idea per diagram, 3 colours maximum, north arrow and scale on every one.

1. **Site analysis**: boundary, setbacks, street(s), neighbours, sun path, prevailing wind, noise, views in/out, existing trees.
2. **Sun path / shadow diagram**: summer-noon and winter-noon sun angles on a section; which facades need shading; where winter sun should reach.
3. **Bubble / adjacency diagram**: rooms as circles sized by area; lines for "must be adjacent", "must be separate". Include public / private / service colour coding.
4. **Zoning diagram**: plot divided into public (guest, majlis), semi-private (family living), private (bedrooms), service (kitchen, laundry, maid, driver, garage).
5. **Circulation diagram**: arrows for guest, family, staff, vehicles, deliveries. Paths should not cross where privacy matters (guest route must never pass the family kitchen or bedrooms).
6. **Massing diagram**: start with the full allowed envelope, then subtract (courtyard, terraces, setbacks), shift, and add (canopies, towers). Show 3 to 4 steps.
7. **Views diagram**: where the best rooms look; frame, borrow, or block.
8. **Structure/grid diagram** (optional at concept): column grid 4-6 m for villas, 7.5-9 m for offices/retail.
9. **Concept sketch/collage**: one hand-drawn-looking section or perspective carrying the whole idea.

### 1.5 Creative techniques that stay honest

- **Subtract from the box**: carve the courtyard, the terrace, the double-height; every cut must have a climate or social reason.
- **One big move + quiet everything else**: a single gesture (a deep canopy, a long wall, a central void) with restrained detailing beats ten gestures.
- **Constraint as feature**: narrow plot becomes the "long gallery"; sloped plot becomes the "split-level"; noisy street becomes the "thick wall with only high light".
- **Borrow the vernacular, translate the detail**: take the principle (shade, stack ventilation, thick mass) and express it in current materials. Copying ornament is decoration; copying the principle is design.
- **Sequence of experience**: arrival, threshold, compression, release. Plan the first 30 seconds inside the door.
- **Reality check before presenting**: structure spans plausible, wet areas stacked, stair compliant, daylight to every habitable room, fire exits, accessibility, parking counts.

## 2. Climate-responsive strategies by zone

General principle: climate decides **orientation, massing, openings, and materials** before style gets a vote. Passive first, mechanical second. Sources: Hassan Fathy's *Architecture for the Poor* and *Natural Energy and Vernacular Architecture*; Climate Consultant / Givoni bioclimatic chart logic; Szokolay and Koenigsberger (see Sources).

### 2.1 Hot-arid (Gulf, Egypt interior, Saudi, Iraq, Libya)

Conditions: summer highs 40-48 C, large day-night swing in desert interior, low humidity inland, dust, intense low-angle east/west sun, mild winter.

| Move | How, in concrete terms |
|---|---|
| Compact, introverted plan | Rooms around a courtyard; minimise exposed external wall per m2 of floor. Courtyard proportions of roughly 1:1 to 1:1.5 in plan, with height-to-width of about 1:1 to 2:1 so walls shade the floor. |
| Courtyard microclimate | Shaded court cools at night, holds cool air by day (cool-air pool). Add a fountain, planting, or water jar for evaporative cooling. Paving in light colour. |
| Thick thermal mass | Walls 300-500 mm of mud brick, stone, or hollow block with insulation to damp the 24-hour swing (best where nights are cool). In coastal humid Gulf cities, mass helps less and insulation + shading matter more. |
| Orientation | Long axis east-west so the long faces point north and south. Minimise glazing on east and west. North glazing is easiest to shade. |
| Shading | Rule of thumb: south windows shaded by horizontal overhang whose projection is roughly 0.4-0.6 times the window height (verify with a sun-path model). East/west openings: vertical fins, mashrabiya screens, or deep reveals, or simply avoid openings. Target a glazing-to-wall ratio of about 15-25% (up to ~30% on the shaded north). |
| Mashrabiya / screen | Timber lattice (or modern perforated metal, GRC, or stone jali) at 30-60% perforation: cuts glare, lowers solar gain, keeps privacy, passes breeze. Place it 100-300 mm outside the glass, not against it. |
| Wind tower (malqaf / badgir) | Tall shaft capturing higher-altitude wind and pushing cooler air down to a living room or basement (sardab). In Cairo-type houses the malqaf is a scoop facing the prevailing north-west wind. Works best with a matching exhaust opening on the leeward side or via the courtyard. Fathy used these in his Egyptian houses. |
| Stack ventilation | Courtyard or stairwell with high-level vents so hot air escapes. A thermal chimney 2-3 storeys high gives noticeable lift on calm days. |
| Roof | Light colour (reflective), insulated, with parapet 1.0-1.2 m for privacy. Vaults and domes shed heat by presenting a larger surface area to the night sky and keeping upper hot air away from occupants. |
| Openings | Small, high, and few on the outer wall; larger toward the courtyard. Double-skin or recessed windows. |
| Landscape | Date palms, shade trees on west; avoid lawn that needs large irrigation volumes; use gravel and native planting. |
| Gulf cooling reality | Most Gulf villas use air conditioning; the design goal is lower load: shading, insulation (U-value of walls near 0.3-0.5 W/m2K is a common ambition; check local code), high-performance glazing (low SHGC around 0.25-0.4), airtight envelope. |

Egypt-specific notes: Cairo and Upper Egypt are hot-arid with a larger diurnal swing, so mass and night flushing work well. Alexandria and the North Coast are more humid-temperate (see 2.2). Avoid west-facing glass; use north-westerly breezes for ventilation.

### 2.2 Hot-humid (Dubai/Doha coastal summer, Red Sea coast, Jeddah, Southeast Asia, Alexandria summer)

Conditions: high humidity, small day-night swing, sea breeze.

- **Open, thin, shaded plans**: one room deep where possible, cross ventilation through opposite openings, porches and verandas.
- **Lightweight, well-insulated roof** and shaded walls; thick mass is less useful because it never cools overnight.
- **Raise the building** a little on a plinth or pilotis for airflow and flood protection.
- **Large roof overhangs** (1.0-1.5 m) with deep verandas; louvres and screens for rain-safe ventilation.
- **Dehumidification** matters: plan mechanical room and air-handling realistically, avoid thermal bridging and condensation on cold surfaces.
- Orient long faces north-south to catch breeze, and use sea-breeze direction in site analysis.

### 2.3 Temperate / Mediterranean

Conditions: warm dry summer, mild wet winter (Athens, Beirut, Alexandria winter, Casablanca, Barcelona, parts of California, southern UK for the mild end).

- **Seasonal shading**: summer shading by pergola, deciduous vines, adjustable shutters; winter sun admitted through south glazing.
- **Cross ventilation + night flush** with moderate thermal mass.
- **Outdoor rooms**: loggia, terrace, courtyard as extra living space for 6-8 months.
- **Insulation plus airtightness** for winter; avoid thermal bridges at balconies (use thermal-break connectors).
- South-facing glass about 25-35% of the south wall with overhang sized so summer high-angle sun is blocked and winter low-angle sun gets in.

### 2.4 Cold / cool-temperate (northern Europe, Scandinavia, northern US/Canada, Japan north)

- **Compact form**: low surface-area-to-volume ratio. Cube beats sprawling wings.
- **Super-insulation and airtightness**: walls U roughly 0.10-0.20 W/m2K, roofs 0.10-0.15, triple glazing. Passive House targets are a design benchmark.
- **Passive solar**: south glazing larger (30-40% of south wall), north small; thermal mass inside the insulation line to store solar gain.
- **Buffer spaces**: mudroom/porch, sunroom, entrance lobby to avoid direct air exchange.
- **Heat recovery ventilation** with ducts planned in the concept, not as an afterthought.
- **Roof**: pitch for snow shedding, deep eaves for ice safety, designed snow loads.
- **Low-angle winter sun**: keep trees and neighbouring massing from blocking it.

### 2.5 One-page climate decision grid

| Move | Hot-arid | Hot-humid | Temperate | Cold |
|---|---|---|---|---|
| Plan depth | Compact, courtyard | Thin, cross-vent | Moderate | Compact |
| Mass | Heavy | Light | Medium | Insulated, mass inside |
| Window area | Small, shaded | Medium, shaded + louvred | Medium | South large, others small |
| Roof | Reflective, insulated | Overhang, insulated, vented | Insulated, shaded terrace | Highly insulated, pitched |
| Outdoor space | Shaded court | Veranda | Terrace/loggia | Sunroom/porch |
| Water | Fountain | Avoid stagnant, drain fast | Pool/garden | N/A |

## 3. Regional typologies and design languages

For each: plan pattern, facade language, materials, roof, typical room list. Treat as starting vocabularies, then adapt; never paste a stereotype.

### 3.1 Gulf villa (UAE, Saudi, Kuwait, Qatar, Bahrain, Oman)

- **Plan pattern**: walled plot with a gated entry; the house is zoned into **guest (majlis) wing**, **family wing**, and **service wing**. Separate male and female guest areas are common (men's majlis near the gate with its own entrance and washroom; women's reception/second majlis deeper inside). Family living, dining, and kitchen sit behind the guest zone. Bedrooms upstairs, master suite often with sitting room and large dressing.
- **Privacy rules**: no direct sightline from the street, neighbours' windows, or the guest entrance into the family garden or living; offset the gate and entrance door; blank or screened upper street windows; high boundary walls (check code limits, often about 2.0-2.5 m); garden shielded by wall plus planting.
- **Service**: maid's room with bathroom (approx 9-12 m2), driver's room (approx 9-12 m2), service yard, laundry, separate service entrance and kitchen access, garage for 2-4 cars, sometimes a "dirty kitchen" (a heavy-cooking prep kitchen) beside the main clean kitchen.
- **Room list (5-bed typical)**: entrance hall, men's majlis, women's majlis, guest washroom(s), family living, dining, kitchen + prep kitchen, 5 bedrooms (1 master suite), family lounge upstairs, maid, driver, store, laundry, prayer nook, garage, pool/garden.
- **Facade language**: modern-Arabic (arches, screens, geometric patterns) or contemporary white/stone boxes; neo-classical columns remain popular. Recessed windows, stone cladding, GRC, perforated metal screens, entrance portal.
- **Materials**: limestone/sandstone cladding, render, GRC, aluminium, glass with low-e, timber screens, marble flooring.
- **Roof**: flat, with parapet, roof terrace and water tank/AC plant enclosures; occasionally domes over majlis.

### 3.2 Egyptian villa and apartment block

- **Villa plan**: reception (salon / "salon baladi" and sitting room) near entrance, separated from living; open or semi-open hall; bedrooms upstairs; staircase central or side; compound or street-front plot with garden and wall. Modern compounds (Cairo outskirts, Sahel) mix villa types in a gated community.
- **Apartment block**: a central core (stairs + 1-2 lifts) serving 2-4 apartments per floor; entrance, reception, living, 2-4 bedrooms, kitchen, 1-3 bathrooms; balconies and light wells; shops on ground floor and a garage in basement/stilts.
- **Facade language**: neo-classical (pilasters, cornices, balustrades, arched windows), modern with large balconies, rendered finishes, stone-clad base; shaded balconies with louvred shutters (shutters are a traditional response). Ground floor in stone, upper floors in paint or cladding.
- **Materials**: reinforced-concrete frame with red-brick or cement-block infill, plaster and paint, stone (Egyptian limestone/marble/granite), ceramic and porcelain tiles, aluminium and wood windows.
- **Roof**: flat roof with parapet, water tanks, and often an extra room ("roof room"); sloped roofs more common in coastal resorts.
- **Design note**: orient bedrooms and living away from west sun; use shading balconies and cross ventilation; plan for generator, water tank, and satellite equipment.

### 3.3 Levant (Lebanon, Syria, Jordan, Palestine)

- **Plan**: central hall house ("liwan" with triple-arched windows) in Lebanon; courtyard house with iwan in Damascus and Aleppo; stone terrace houses in Palestine; plans that open through arcaded loggias.
- **Facade**: limestone ashlar, triple arcade windows, red clay tile roof (Lebanese central-hall house), carved stone lintels, wrought-iron balconies.
- **Materials**: local limestone, lime plaster, timber beams, red clay roof tile, wrought iron.
- **Roof**: hipped with red tile in Lebanese heritage houses; flat terraced roofs in drier areas.
- **Rooms**: central salon, bedrooms around the hall, summer kitchen, courtyard fountain, roof terrace.

### 3.4 Moroccan riad

- **Plan**: inward-looking courtyard house with a central garden/fountain (riad means garden), rooms on 2-3 floors around the court, narrow elongated rooms with entrance doors at the centre, roof terrace, a bent entrance (skiffa) for privacy.
- **Facade**: nearly blank street face with a heavy door; interior facade rich with zellige tile, carved plaster (gebs), carved cedar, wrought iron.
- **Materials**: rammed earth/tabia or brick, lime plaster (tadelakt in wet areas), zellige tile, carved cedar, marble columns.
- **Roof**: flat terrace, sometimes with green tile pitched sections over upper galleries.
- **Rooms**: skiffa, courtyard, salons, bedrooms, kitchen, hammam, roof terrace.

### 3.5 Mediterranean (Spain, Italy, Greece, Southern France; also popular for Gulf/Egypt resorts)

- **Plan**: simple volumes around loggias; terraces linked to garden; shaded pergola outdoor dining.
- **Facade**: white or ochre render, small deep-set windows, wooden shutters, arched openings, tiled roof, pergola.
- **Materials**: lime render, terracotta, local stone, timber, wrought iron.
- **Roof**: low-pitched clay tile (Spanish/Italian), flat terraces (Cycladic).
- **Rooms**: loggia, kitchen-dining, living, bedrooms, terrace, small pool.

### 3.6 Modern minimal

- **Plan**: open plan; strong geometry; double-height living; indoor-outdoor connection; concealed storage.
- **Facade**: clean volumes, large glazing, flush details, shadow gaps, restricted palette (2-3 materials).
- **Materials**: concrete, white render, large-format porcelain, timber slats, steel, glass.
- **Roof**: flat with hidden drainage, deep cantilevered slab edge.
- **Warning**: all-glass minimal boxes fail in hot-arid zones; combine with deep overhangs, solid walls, and shading.

### 3.7 Neo-classical (popular in Egypt and Gulf for villas and palaces)

- **Plan**: symmetrical, central entrance hall with grand stair, formal reception rooms flanking.
- **Facade**: tripartite composition (base, piano nobile, attic/cornice), columns or pilasters, pediment, balustrades, quoins, tall windows with architraves and moulded panels.
- **Materials**: light stone, GRC mouldings, marble, wrought iron, gilt details.
- **Roof**: balustraded flat roof or low hipped.
- **Craft warning**: proportion is everything. Column height-to-diameter around 8:1 to 10:1 (Corinthian/Composite), cornice depth about 1/8 to 1/10 of the order height, windows align on axis. Cheap versions look cartoonish when proportions or detail depth are off.

### 3.8 Contemporary Islamic

- **Plan**: courtyard/riwaq, hierarchy from public to private, axial entrance with turn; majlis; qibla-aware prayer space.
- **Facade**: abstracted geometry (8-point star, hexagon grids), parametric screens, arches simplified, calligraphy limited and respectful, deep reveals.
- **Materials**: stone, GRC, perforated metal, mashrabiya in timber or aluminium, glass fibre reinforced concrete, brass accents.
- **Roof**: flat with parapet; dome or vault where meaningful.
- **Design note**: use geometry as structure of shading (screen as environmental device), not as pasted ornament.

### 3.9 Japanese

- **Plan**: modular grid (tatami-based, 910 x 1820 mm tatami, ~1.65 m2 each), engawa (veranda) buffering interior and garden, sliding screens (shoji, fusuma), genkan (entry step down for shoes), compact rooms with multi-use.
- **Facade**: timber lattice, deep eaves, horizontal emphasis, tonal restraint.
- **Materials**: timber (cedar, cypress), plaster, paper screens, tile, stone base.
- **Roof**: hipped or gabled with long overhangs, ceramic tile.
- **Rooms**: genkan, living/dining/kitchen (LDK), tatami room, bathing room with separate toilet, small garden.

### 3.10 Scandinavian

- **Plan**: simple, compact, light-filled; open kitchen-living; connection to outdoors; entrance with generous storage.
- **Facade**: timber cladding (painted or natural), pitched roof, large windows on south, low sill heights to the landscape.
- **Materials**: pine/spruce/larch, light plaster, wool, brick, steel roofing.
- **Roof**: simple gable at 30-45 degrees, snow guards, deep eaves.
- **Rooms**: hall/entry, kitchen-dining, living, 2-4 bedrooms, utility, sauna in many homes.

### 3.11 US suburban

- **Plan**: detached house on a lot, front lawn, 2-car garage facing the street, open kitchen-family room, formal living/dining optional, master suite on ground or upstairs, basement in colder states.
- **Facade**: gabled forms, front porch, siding (vinyl/fibre cement/wood), brick or stone veneer accents, symmetrical windows.
- **Materials**: timber frame (stick built), sheathing, siding, asphalt shingles, drywall.
- **Roof**: gable/hip, 4:12 to 8:12 pitch, asphalt shingle.
- **Rooms**: foyer, living, dining, kitchen, family room, 3-5 bedrooms, 2-3.5 baths, laundry, garage, basement; code requirements for egress windows, smoke/CO alarms.

### 3.12 UK terraced / semi-detached

- **Plan**: narrow frontage 4.5-6 m, deep plan 9-12 m; ground floor front room + back living/kitchen, stairs along party wall; two or three bedrooms upstairs, bathroom over kitchen; rear garden 10-15 m.
- **Facade**: brick with stone sills and lintels, bay window (Victorian), sash windows, door with fanlight; semis: paired gable or hip with side passage.
- **Materials**: London stock or red brick, slate or clay tile, timber sash or uPVC, render on rear extensions.
- **Roof**: pitched 30-40 degrees, chimneys, loft conversions with dormers.
- **Rooms**: hall, front reception, rear kitchen-diner, 2-3 bedrooms, bathroom, loft.

## 4. Precedent projects (25+) and the transferable idea

Use precedents as *ideas to translate*, not images to copy. Format: project, architect, place - idea.

### Arab world and Islamic context

1. **New Gourna Village**, Hassan Fathy, Luxor, Egypt (1945-48) - mud-brick vaults and domes built with local labour, courtyards and wind-catching to cool at near-zero cost. Idea: low-tech climate response and community participation. Note: only a portion was built, and Fathy himself called the experiment a failure (see Sources).
2. **Louvre Abu Dhabi**, Jean Nouvel, Abu Dhabi, UAE (2017) - a 180 m diameter "rain of light" dome of layered perforated steel and aluminium stars over a cluster of galleries. Idea: roof as shading canopy that creates a microclimate and dappled light.
3. **Msheireb Downtown Doha**, Allies and Morrison / AHR / Arup and others, Doha, Qatar - dense low-rise district with narrow shaded streets, courtyards, and a Qatari design language. Idea: urban form as climate tool; revive the *sikka* (narrow alley) at modern scale (see RIBA entry in Sources).
4. **Al Bahr Towers**, Aedas with Arup, Abu Dhabi, UAE (2012) - dynamic mashrabiya-inspired facade of umbrella-like units that open and close with the sun. Reported to cut solar gain by around 50% (see Sources). Idea: traditional screen reinterpreted as responsive skin.
5. **Institut du Monde Arabe**, Jean Nouvel, Paris, France (1987) - facade of light-sensitive diaphragms on a geometric grid (original mechanism has been unreliable over time). Idea: geometry as cultural signifier and light controller; warning that complex mechanisms need maintenance.
6. **King Abdullah Petroleum Studies Centre (KAPSARC)**, Zaha Hadid Architects, Riyadh, Saudi Arabia (2017) - interlocking honeycomb-like hexagonal volumes with shaded internal streets. Idea: cluster of pods linked by shaded interstitial space.
7. **Sheikh Zayed Grand Mosque**, Abu Dhabi, UAE (2007; design led by Yousef Abdelky, completed by multiple firms) - 82 domes, white marble, reflecting pools, vast courtyard. Idea: repeated simple geometry plus water gives monumentality and a cooler forecourt.
8. **National Museum of Qatar**, Jean Nouvel, Doha, Qatar (2019) - interlocking discs inspired by the desert rose crystal. Idea: form drawn from a local natural object, organised as a continuous gallery sequence around a courtyard.
9. **Museum of Islamic Art**, I. M. Pei, Doha, Qatar (2008) - stacked cube with central dome and atrium, inspired by the ablution fountain of Ibn Tulun Mosque in Cairo. Idea: distil an ancient precedent into pure geometry.
10. **Dar Al-Hajar / Yemeni tower houses**, vernacular, Sana'a and Wadi Dhar, Yemen - multi-storey stone/mud houses with stacked functions and white-lined windows. Idea: vertical density, stacking by privacy, decorative windows as identity.
11. **Fathy private houses**, Hassan Fathy, Egypt - courtyard houses using malqaf wind-catchers, mashrabiya, and vaulted rooms (verify project names on ArchNet before citing). Idea: traditional cooling devices in contemporary private homes.
12. **Beit Al Quran**, Manama, Bahrain (1990) - Islamic geometry around a calm central court (verify architect credit on ArchNet before citing). Idea: contemporary Islamic composition with clear axes and restrained stone.
13. **Bibliotheca Alexandrina**, Snohetta, Alexandria, Egypt (2002) - tilted disc roof with north-facing glazing. Idea: roof tilt gives even north light; the circle reads as a sun disc.
14. **Zayed National Museum**, Foster + Partners, Abu Dhabi, UAE - falcon-wing towers that work as solar chimneys. Idea: form as ventilation device.

### Global

15. **Villa Savoye**, Le Corbusier, Poissy, France (1931) - pilotis, free plan, ribbon windows, roof garden. Idea: the five points as a design checklist; the promenade architecturale.
16. **Fallingwater**, Frank Lloyd Wright, Pennsylvania, USA (1937) - cantilevered terraces over a waterfall. Idea: let landscape shape the section.
17. **Barcelona Pavilion**, Mies van der Rohe, Barcelona (1929) - free-flowing planes, travertine, onyx, glass. Idea: material richness and flowing space with minimal elements.
18. **Therme Vals**, Peter Zumthor, Switzerland (1996) - stacked stone blocks with voids between. Idea: material as concept; light slots in the roof.
19. **Church of Light**, Tadao Ando, Osaka, Japan (1989) - concrete box with a cruciform slit. Idea: single powerful light gesture in an otherwise austere room.
20. **Kimbell Art Museum**, Louis Kahn, Fort Worth, USA (1972) - cycloid vaults with skylight slits, silvery daylight. Idea: structural module doubles as daylight device.
21. **Maggie's Centres**, various architects (Rogers, Koolhaas, Hadid, Foster and others), UK - small domestic-scale cancer-care houses with gardens and a central kitchen table. Idea: healthcare programmed as a homelike sequence, not a corridor.
22. **Casa Gilardi**, Luis Barragan, Mexico City (1976) - colour-washed walls, pool-dining room, filtered light. Idea: colour and water as architectural materials.
23. **Sendai Mediatheque**, Toyo Ito, Sendai, Japan (2001) - thin floor plates held by tube-like structural columns. Idea: structure as spatial and circulation device.
24. **Sou Fujimoto House NA**, Tokyo, Japan (2011) - glass house of 21 small floor levels as a "tree". Idea: privacy through distance and layering rather than walls.
25. **Alvaro Siza, Boa Nova Tea House**, Matosinhos, Portugal (1963) - low building threading between rocks. Idea: fit to the site so the building feels discovered.
26. **Alhambra / Generalife** (vernacular precedent), Granada, Spain (13th-14th c.) - courtyards with reflecting water, layered arcades. Idea: sequence of courtyards, water as cooling and reflection.
27. **Villa Tugendhat**, Mies van der Rohe, Brno (1930) - onyx wall, curtain-glazed living, winter garden. Idea: dissolving boundary between rooms and garden, with environmental buffer.
28. **Bosco Verticale**, Stefano Boeri, Milan, Italy (2014) - towers with planted balconies. Idea: vegetation as shade and biodiversity layer (note: requires heavy maintenance).
29. **Hanok / Japanese minka** (vernacular), Korea / Japan - timber frames with deep eaves and sliding screens. Idea: adaptable partitions and seasonal use of spaces.
30. **Marina Bay Sands / Gardens by the Bay Supertrees** (global tropical precedent), Singapore - vertical gardens that act as ventilators and shade. Idea: landscape-engineering hybrid in hot-humid zones.

Awards to browse for Arab/Islamic ideas: the Aga Khan Award archive and Pritzker laureate citations (see Sources). Pritzker laureates useful for climate and craft: Zumthor, Ando, Siza, Doshi (2018; hot-climate housing, courtyards). Hassan Fathy is a reference figure but not a Pritzker laureate.

## 5. Facade composition rules

### 5.1 Order before decoration

A facade reads as "good" when three things are controlled: **proportion, rhythm, and hierarchy**. Decide the order before choosing materials.

### 5.2 Proportion systems

- **Grid first**: lay a modular grid (structural bay, typically 3.6-4.5 m in villas, 7.5-9 m in offices) and align openings, panel joints, and floor lines to it.
- **Golden ratio (1:1.618)** and simple ratios (1:1, 1:2, 2:3, 3:4, 3:5): use them to proportion the overall facade, a window, or a bay. Do not treat them as magic; they are a consistent discipline so elements feel related. Example: a 10 m wide facade, 6.2 m tall.
- **Window proportions**: vertical windows (1:1.5 to 1:2) feel classical and dignified; horizontal ribbons (1:2 or wider) feel modern; square feels static. Use one or two window types per facade, not six.
- **Floor-to-floor**: 3.0-3.4 m residential, 3.6-4.2 m offices/retail (rule of thumb), with 2.7 m clear height minimum and 3.0 m+ for living spaces in hot climates (check code).

### 5.3 Rhythm and repetition

- Pick a rhythm (ABAB, AAB, or symmetrical) and stick to it. A break in rhythm (a bay window, a large window, the entrance) should mark the *most important* element, and only one.
- Space windows so the pier (solid between) is at least the same width as the window or about 0.6-1.0 times the window width in classical compositions.
- Repetition + one deliberate exception = interest. Repetition without exception = monotony; random variation = noise.

### 5.4 Solid-to-void ratio

| Climate/style | Typical glazing/wall |
|---|---|
| Hot-arid traditional | 10-20% voids |
| Gulf contemporary villa | 20-30%, with shading |
| Temperate/modern | 30-45% |
| Cold, passive solar | 30-40% south, 10-20% north |
| Curtain wall office | 50-70% (needs high-performance glazing and shading) |

Heavier solid = privacy, shade, and permanence. Heavier void = openness, but heat and glare. Cluster voids rather than scattering evenly.

### 5.5 Window alignment

- Align heads (top edges) across the facade at the same height, typically at door-head height (about 2.1-2.4 m above floor) so the facade has a clear horizontal datum.
- Stack windows vertically across floors on the same axis; centre them on bays or structural grid.
- Do not let a window cut a corner or fall within 300-450 mm of a corner without intent (structural and visual weakness).
- Align internal partitions with mullions or piers, not mid-pane, so interior walls do not hit the glass awkwardly.
- Entrance door: centred on a clear axis or deliberately offset with a compensating element.

### 5.6 Base - middle - top

Even in modern work, the three-part idea gives scale and clarity.

| Part | Role | Typical treatment |
|---|---|---|
| Base | Ground plane, weather protection, durability, grounding | Stone, darker colour, plinth 0.6-1.2 m, rustication, planter |
| Middle | Habitable body, windows | Primary finish, main rhythm |
| Top | Crowning, shadow line, roof edge | Cornice, projecting slab, parapet cap, recessed attic, pergola |

On towers: podium-shaft-crown. On houses: plinth-wall-eave.

### 5.7 Depth, shadow, and detail

- **Depth creates quality**: a reveal of 150-300 mm, a projecting frame, or a screen gives shadow and avoids a flat "sticker" look. Render will show this immediately.
- Use no more than **3 materials** and 2 colours (plus accent) per facade.
- Entrance gets the highest detail density; service sides get the least.
- Light and shadow: design the facade for low-angle morning/evening light, when renders look best and the real building too.
- Consider **night facade**: lighting at reveals, under eaves, and on entry portal.

### 5.8 Common facade mistakes (checklist)

- Window sizes random across the elevation.
- Columns without proper base/capital/entablature; ornament with no depth.
- Floating balconies not related to the structure.
- Glass walls on east/west in hot climates.
- AC condensers visible on the facade; hide them in screened niches.
- Roof-top equipment forgotten; plan a screened plant zone.
- Mismatch between floor plan windows and elevation windows (always cross-check).

## 6. Program templates (typical area ranges - rules of thumb)

Label these as assumptions in any client pack. Areas vary by country, budget, and code. Figures below are gross floor area (GFA) unless stated as net room area.

### 6.1 Villa (private house)

| Type | Typical built-up area | Notes |
|---|---|---|
| 3-bedroom | 220-320 m2 (Gulf: often larger, 350-450 m2) | 1 majlis, family living, dining, kitchen, maid |
| 4-bedroom | 320-450 m2 | + family lounge, bigger master suite |
| 5-bedroom | 450-650 m2 | + second majlis, driver, study |
| 6-bedroom | 600-900 m2 | + separate female majlis, home cinema, gym, guest suite |

Room net-area ranges (rule of thumb):
- Master bedroom 20-30 m2 + dressing 8-15 m2 + bathroom 8-12 m2
- Secondary bedroom 14-20 m2 + bathroom 5-7 m2
- Living room 30-50 m2; family lounge 20-35 m2
- Dining 18-35 m2; kitchen 15-25 m2 (+ prep kitchen 8-12 m2)
- Majlis 30-60 m2 (men's); women's majlis 25-45 m2
- Maid room 9-12 m2; driver room 9-12 m2; laundry 6-10 m2; store 4-8 m2
- Entrance hall 10-20 m2; staircase 10-15 m2
- Garage 2 cars about 36 m2 (3.0 x 6.0 m minimum per space)
- Circulation target: 12-18% of GFA.
- Plot coverage in Gulf cities is commonly limited (often 50-70%) by municipality; check.

### 6.2 Apartment unit types (net unit area including internal walls)

| Type | Typical net area | Layout notes |
|---|---|---|
| Studio | 30-45 m2 | Single room, kitchenette, bath |
| 1-bedroom | 50-75 m2 | Living + kitchen, 1 bath |
| 2-bedroom | 85-130 m2 | 2 baths, balcony |
| 3-bedroom | 130-200 m2 | 2-3 baths, maid room in Gulf/Egypt |
| 4-bedroom / penthouse | 200-400 m2 | Roof terrace |

Egypt common range: 100-180 m2 for 2-3 bedrooms; Gulf: larger. Efficiency target (net saleable / gross) is 75-85%; core: 1 lift per ~25-30 units low-rise (check code), two stairs for fire egress where required.

### 6.3 Small office (20-60 staff)

- Workstation 6-8 m2 per person including circulation (open plan: roughly 8-12 m2 per person gross).
- Meeting room 12-20 m2 (6-10 seats), manager office 12-18 m2, reception 15-25 m2, pantry 10-20 m2, server/print 6-10 m2, WCs per code.
- Total small office floor plate: roughly 10-15 m2 per person gross.
- Column grid 7.5-9 m; floor-to-floor 3.6-4.0 m; raised floor or ceiling void for MEP.

### 6.4 Retail

- Small shop unit 30-80 m2; width 4-6 m, depth 8-12 m.
- Supermarket/mini-market 200-1,000 m2; storefront glazing 60-80% of frontage; storage 15-25% of area.
- Mall-anchor units 1,000+ m2.
- Provide service route separated from customers, signage zone above door, 3.5-4.5 m clear height, loading access.

### 6.5 Clinic (small outpatient)

- Consulting room 12-16 m2 each (desk, exam couch, hand-wash).
- Treatment room 14-20 m2; procedure room 20-25 m2; dental surgery 14-18 m2.
- Waiting 1.5-2 m2 per seat; reception 12-20 m2; toilets (accessible) required.
- Typical small clinic with 4-6 consulting rooms: 250-450 m2.
- Planning: separate patient and staff circulation, clean and dirty utility rooms, waste storage, privacy at consultation doors (no direct visual access), infection control, accessibility, ventilation, local health-authority approval.

### 6.6 Mosque basics

- **Prayer space area**: about 0.8-1.0 m2 per worshipper (rule of thumb, commonly quoted 0.9-1.2 m2 including a margin). A row of worshippers: about 0.8 m shoulder-to-shoulder width per person, and each row about 1.2 m deep.
- **Qibla orientation**: the prayer wall (qibla wall) faces the Kaaba in Makkah. Compute it from the site coordinates using great-circle bearing; do not guess. Approximate bearings from true north: Cairo about 136 degrees (south-east); Riyadh about 244; Dubai about 258; Doha about 250; Kuwait City about 244; London about 119; New York about 58. Verify with an authoritative qibla calculator and a site survey; the building grid may need to rotate relative to the street grid, handled by a lobby or wedge-shaped transition.
- **Mihrab** (niche) in the qibla wall, **minbar** (pulpit) beside it, **minaret** optional (symbolic), **dome** optional.
- **Ablution (wudu) area**: separate for men and women, near the entrance, 1 tap per ~15-20 worshippers; floors drain; shoe storage at entry.
- **Women's section**: separate entrance and a mezzanine or screened area; commonly 20-30% of men's area in practice (varies).
- **Washrooms, imam office, ablution, courtyard (sahn), parking** for Friday prayers.
- Avoid placing toilets or ablution so users face the qibla while using them, and avoid walking on prayer carpets in street shoes: provide entry shoe zone.
- Clear column-free prayer hall is ideal; rows should align with qibla, not building grid.

## 7. Presentation: the client concept pack

### 7.1 What a client concept pack contains

Aim for 12-20 slides/pages. Order matters: story first, drawings next, renders last (or one hero upfront).

1. **Cover**: project name, client, date, hero render (optional).
2. **Brief and understanding**: client needs in your words, plot data, key constraints, assumptions list.
3. **Site analysis**: sun, wind, access, views, setbacks, code constraints.
4. **Precedent / mood board**: 4-6 images that capture atmosphere; credit the sources.
5. **Concept statement + parti diagram**: the formula from section 1.3.
6. **Three options** (compact), with the recommendation and reason.
7. **Zoning and circulation diagrams**.
8. **Massing diagram series**.
9. **Floor plans** (ground, first, roof) with room names and areas, north arrow, scale, furniture drawn.
10. **Sections**: one long section showing height, courtyard, and light; one cross section.
11. **Elevations**: all four, with materials noted.
12. **Climate strategy page**: sun path, shading, ventilation arrows, glazing %.
13. **Material and colour board**.
14. **Renders** (see 7.2).
15. **Area schedule**: table by room and floor with total GFA and coverage vs allowed.
16. **Next steps**: what the client must decide, rough timeline, fee/approval path, risks.

Always include a one-line disclaimer: "Concept stage - not for construction. Areas and costs indicative."

### 7.2 Render shot list

| # | Shot | Why | Camera notes |
|---|---|---|---|
| 1 | **Hero exterior at dusk** (blue hour) | Sells the idea; interior lights glow | 3/4 view from street height (1.6 m), 24-35 mm lens equivalent, sky gradient, warm interior lighting, wet-ground reflection optional |
| 2 | **Entrance / arrival** | Shows the threshold and craft | Eye height, door framed in depth, lighting from above, planting |
| 3 | **Living room** | Daily life; shows scale and view | Wide but not distorted (22-28 mm), vertical lines straight, daylight plus warm lamps |
| 4 | **Majlis (Gulf)** or formal reception | Cultural centrepiece | Symmetric view along axis, seating perimeter, ceiling detail, lighting layers |
| 5 | **Kitchen / dining** | Family hub | Natural light, material close-up |
| 6 | **Master suite** (optional) | Emotional appeal | Soft light, window to garden |
| 7 | **Courtyard / garden / pool** | Climate response made visible | Shaded daytime view, people using it |
| 8 | **Aerial / bird's-eye** | Context and massing | 30-45 degree view, roof plan legible, site boundary |
| 9 | **Facade detail** | Material and shadow | Close raking light on screen or stone |
| 10 | **Night aerial or night facade** | Lighting design | Warm accent lighting, reveals |

Render hygiene: straight verticals, human-scale entourage (a few people, not crowds), correct season/trees for the region, no fantasy skies that contradict the climate, honest materials, no floating furniture, avoid oversaturation.

### 7.3 Material board

One page. Include:
- 5-8 swatches: primary wall finish, secondary finish, roof/paving, screen/shading element, window frame colour, floor finish interior, one accent (timber, brass, stone).
- Name, supplier/type, and finish for each (e.g., "honed local limestone, 20 mm").
- Palette rule: 60% primary neutral, 30% secondary, 10% accent.
- A tiny sun/heat note when relevant (light roofs, low-emissivity glass).

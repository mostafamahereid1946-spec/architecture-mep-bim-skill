# Malaysia — Drafting & Code Reference

Legend: **✓** = read this session (UBBL 1984 text as hosted on SlideShare — an OCR copy with possible digit errors; PAM Practice Bureau note) — URLs in §8. **⚠ verify** = memory/secondary/not opened. The official gazetted text (Laws of Malaysia, Legal Research Board compilation) should be checked for any number that goes on a drawing.

**Rule of thumb:** the **UBBL 1984** (Uniform Building By-Laws, G.N. 5178/84, made under Street, Drainage and Building Act 1974 [Act 133]) is the national baseline adopted by states/local authorities (**PBT — Pihak Berkuasa Tempatan**: DBKL, MBPJ, MBSA, MBJB, MBIP, etc.), but **plot ratio, setbacks, height and coverage come from the local plan (Rancangan Tempatan) and PBT guidelines** ⚠ — ask for the *planning permission (kebenaran merancang)* conditions.

---
## 1. Units, scales, sheets, title block, language

| Item | Practice |
|---|---|
| Units | Metric (mm on plans, m on site) — UBBL is metric ✓; feet appear only in legacy plot titles ⚠ |
| Language | English or Bahasa Malaysia (BM) — submissions typically English with BM titles on forms (Borang) ⚠ |
| Sheets | ISO A0–A3; A1 for permit prints ⚠ |
| Scales | Location 1:1000+, site 1:200–1:500, plans/elevations/sections 1:100 (1:50), details 1:20 ⚠ |
| Title block | Project name, lot no./mukim/daerah, client (Pemilik), **PSP** (Principal Submitting Person) with registration (LAM/BEM/PAM) ⚠, drawing no., scale, date, "Perancang" ✓ practice |
| Levels | Reduced level (RL) to Peninsular Malaysia mean sea level; Sabah/Sarawak own datums ⚠ |
| Coordinates | GDM2000 / RSO ⚠ |
| Area terms | GFA, plot ratio, plot coverage, "luas lantai kasar" ⚠ |

## 2. CAD layer/file naming practice + authority CAD/e-submission rules

| Topic | Practice |
|---|---|
| Layer naming | No mandated scheme; **CIDB/JKR** guidelines exist; offices use `A-WALL`, `A-DOOR` style or BM names ⚠ |
| Submission portals | **OSC Online 3.0 Plus** (One-Stop Centre) — planning permission & building plan approval; **e-Submission** per PBT; **JPBD Planning** portal ⚠ |
| Formats | PDF drawings signed by PSP; some PBT still ask hard copies (A1 folded) ⚠; DWG for pre-checking ⚠ |
| Stages | Planning permission → building plan (BP) approval → Commencement (Notice) → **CCC (Certificate of Completion and Compliance)** issued by the PSP — replaced Certificate of Fitness (CF) in Selangor/ WP from 2007 amendments to Act 133 ⚠ |
| Fire | Separate **BOMBA (JBPM — Jabatan Bomba dan Penyelamat)** fire-plan approval and Fire Certificate (Perakuan Bomba) ✓ practice, Fire Services Act 1988 |

## 3. Drafting conventions

- **Plans labelled** in English/BM: "Bilik Tidur / Bedroom", "Dapur / Kitchen", "Bilik Air / Bathroom", "Ruang Tamu / Living", "Anjung / Porch", "Tandas / WC" ✓ practice.
- **Floor plans show**: lot boundaries, setbacks, drain reserve (rizab parit), road reserve, perimeter fence, TNB meter room (**TNB** Tenaga Nasional Berhad) ⚠.
- **Dimensions** in mm; levels `+0.000 FFL = +RL`; roof pitch in degrees.
- **Door/window schedule** with sizes and fire rating (e.g. `FD30S/ FD60`) ⚠.
- **Elevations**: show finish materials and colour codes; louvres for ventilation.
- **BCA-style notes**: "All works to comply with UBBL 1984 (latest amendments), Fire Services Act 1988 and MS 1184" ⚠.
- **Setting-out** from lot corner; adjacent drains and utilities shown (TM, Air Selangor, IWK) ⚠.

## 5. Key numbers (UBBL 1984 — read from OCR copy; ✓ with ⚠ caution on digits)

| Item | Value | UBBL |
|---|---|---|
| Habitable room (residential) — first room | **≥ 11 m²** | by-law 42(1) ✓ |
| Second habitable room | **≥ 9.3 m²** | 42(1) ✓ |
| Other habitable rooms | **≥ 6.5 m²** (PAM note confirms 6.5 m² floor area test) | 42(1) ✓ |
| Habitable room width | **≥ 2 m** | 42(2) ✓ |
| Kitchen | **≥ 4.5 m²** and **≥ 1.5 m** wide | 42(3) ✓ |
| WC/latrine sizes | pedestal 1.5×0.75 m; other 1.25×0.75 m; bathroom ≥ 1.5 m² (w ≥ 0.75 m); bath+WC ≥ 2 m² | 43 ✓ |
| Room heights (residential, not shophouse) | living/bedrooms **2.5 m**; kitchens **2.25 m**; bathrooms/WC/porch/garage **2.0 m**; no part of room < 2 m | 44(1),(2) ✓ |
| Shophouse heights | ground 3.0 m; upper 2.5 m (2.55 m when depth > 10.5 m) | 44(3) ✓ |
| Other buildings | ground 3.0 m; above 2.75 m; basement 2.5 m | 46 ✓ |
| Light (windows) | glazing ≥ **10%** floor area; free air opening ≥ **5%** | 39(1) ✓ |
| Toilet ventilation | ≥ 0.2 m² per fixture | 39(4) ✓ |
| Stair rise / tread | riser **≤ 180 mm**; tread **≥ 255 mm** (uniform) | 106(1) ✓ |
| Stair landing | ≥ stair width deep; in residential landing ≥ **1.8 m** at intervals ≤ **4.25 m** | 106(3), 108(1) ✓ |
| Handrail | height 825–900 mm above nosing; ≥ 900 mm at landings; two sides if stair ≥ 1,100 mm (non-residential) | 107 ✓ |
| Headroom over stairs | ≥ **2 m** | 110(2) ✓ |
| Exits | ≥ **2** separate exits per storey; exits ≥ 4.5 m apart (storey exits) / ≥ 5 m apart | 166, 167, 174 ✓ |
| Exit unit | 552 mm per unit; no individual access < 700 mm; escape stair min width **1,104 mm** (900 mm if < 50 occupants) | 177(e), 181 ✓ |
| Occupant flow | 60 persons/min (doors/corridors); 45/min (stairs) | 182 ✓ |
| Single-staircase building | top floor ≤ 12 m; travel ≤ 12 m (≤ 30 m if openable windows) | 194 ✓ |
| Roof access stair | buildings > 30 m | 195 ✓ |
| Fire-escape stair ventilation | ≥ 1 m² free area per floor; 5% of enclosure area at top (unventilated) | 198, 199 ✓ |
| Stair pressurisation | buildings above **45.75 m** | 202 ✓ |
| Travel distance — assembly | 45 m unsprinklered / 60 m sprinklered; **other occupancies: Seventh Schedule** (not read) | 188 ✓ |
| Detached building clearances | ≥ 2 m to lot boundary; ≥ 4 m between buildings; open space ≥ 1/3 of built-on area (residential) | 34, 32 ✓ ⚠ read from summary |

## 6. Permit drawing set

1. **Planning permission** (kebenaran merancang): location plan, layout plan, site plan, elevations ⚠
2. **Building plan (BP)**: architectural plans/elevations/sections, roof plan, drainage, schedule of areas, door/window schedule ⚠
3. **Structural (C&S) submission**: engineer's calcs, foundation, soil investigation, geotech where required ⚠ (Form for submission; PE sign-off)
4. **Fire plan** to BOMBA (JBPM) and **MEP** submissions: electrical (ST-licensed), mechanical ventilation, plumbing ⚠
5. After construction: CCC by PSP; BOMBA Fire Certificate; utility (TNB/IWK) acceptance ✓ practice

## 7. Common rejection reasons

- Plot ratio / setbacks differ from planning approval; building line to road reserve or drain reserve violated.
- Habitable room < 11 / 9.3 / 6.5 m² or width < 2 m; ceiling height < 2.5 m; kitchen < 4.5 m².
- Stair riser > 180 mm or tread < 255 mm; no landing; headroom < 2 m (UBBL 106/110).
- Only one exit where two required; escape stair width < 1,104 mm; no stair ventilation (UBBL 166–202).
- Windows < 10% of floor area or ventilation < 5% (UBBL 39).
- Missing C&S, M&E, or BOMBA approvals; PSP unregistered.
- Wrong edition of UBBL / state variation (Sabah, Sarawak) cited.
